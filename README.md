# The One-Line Cat Joke That Lands

> The vet says my cat is overweight. The cat says the vet is a snitch.

One joke about cats, one line, 68 characters. No setup beyond the line itself,
no explanation after the punchline — the cat snitching on the vet is the turn,
and the punchline lands because the cat, not the owner, gets the last word.

## Reproducibility

Run the entry with Python 3:

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt`. The output is deterministic:
running it twice produces byte-identical files, 68 characters, within the
1–200 character gate.

The joke was chosen from 8 candidates in a local pairwise tournament
(28 pairs, judged in both orders, 56 judge calls) against the published
judge brief, using the Caffeine Inference router as judge. It won with a
0.671 win rate (4 of 7 games). Full call records: `tournament_results.jsonl`.
